# Profile maintenance

This repository supplies the profile README for [YuanYCoding](https://github.com/YuanYCoding).

- Edit `README.md` to update the introduction, project links, or featured work.
- Edit `scripts/generate_assets.py`, then run `python scripts/generate_assets.py` to regenerate both image themes.
- Each `<picture>` uses a light and dark source with a light-mode fallback. Keep descriptive alt text and plain-text project links.
- Artwork is self-contained SVG. It does not depend on a statistics service, remote fonts, API keys, or scheduled workflows.
- Project descriptions should stay grounded in the public repositories. Avoid presenting unverifiable expertise, employer information, user metrics, or deployment status as facts.

Native GitHub pinned repositories are managed separately from the featured links in this README. Suggested selection: `vibe-scaffold-kit`, `use-agentsmd`, `regex-forge`, `decision_expert`.
